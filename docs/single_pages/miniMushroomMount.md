# Mini Mushroom Mount

New Mushrooms with actual 3D Models, that can be placed anywhere.
It is placed just like turtle eggs, with a cap of 4 on the same block, each amount of mushrooms has a different 3D Model.

## Crafting

It can be made in the Stonecutter by using:

* minecraft:red_mushroom
* minecraft:brown_mushroom

both give a single sylvis:mini_mushroom_mount.

or by using:

* minecraft:brown_mushroom_block
* minecraft:red_mushroom_block
* minecraft:mushroom_stem

to get 4 sylvis:mini_mushroom_mount.
